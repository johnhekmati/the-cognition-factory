Install & updates — second machine, second person

How a household adult runs the app without the founder narrating. Same loop as the site: map · practice · save place.

In one line. Copy the whole build, sign in as yourself, point at libraries once, then do a 10-minute first win.

What you need

  • A current app build from your household admin (Windows Release folder or Android APK)
  • Optional: xAI API key for co-pilot chat (admin sets under Settings → Grok API)
  • Study libraries on disk (Deep learning Core + Practice carts) — admin links paths once

Windows

  1. Copy the whole Release folder (exe + DLLs + data\), not the exe alone.
  2. Place it somewhere stable; shortcut the exe if you like.
  3. Launch → pick your person → unlock (defaults until you change them under Settings → My sign-in).
  4. If libraries are missing: admin sets Settings → Paths, or first-run setup.

Updates

Admin drops a new Release folder (or overwrites files). Keep Documents\TheCognitionFactory\ — profiles, Progress, park notes live there. Sign-in passwords use secure storage on that PC.

Android

  1. Install the APK your admin provides (sideload when not on a store).
  2. Grant storage access if asked (libraries outside the app sandbox).
  3. Sign in as yourself. Paths must live on the device (not Windows drive letters).

Updates

Install the newer APK over the old one. Re-link folders if data was cleared.

New person in the household

  1. Admin: Profiles → add person (snack shows default username/password).
  2. They launch, pick their name, unlock.
  3. Settings → My sign-in — change password.
  4. Same libraries; separate Progress and Save place.

First 10 minutes (definition of done)

You are done when a Save place note exists — not when a course is finished.

  1. Deep learning or Practice
  2. Load materials (chat if needed)
  3. One honest bite
  4. Park: “Next time I will…”

What we do not ship yet

  • Always-on auto-update / mandatory Play Store listing
  • Cloud backup of profiles
  • Enterprise MDM zero-touch (see enterprise SOP)

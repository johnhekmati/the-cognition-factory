# Form & Frame Design
## Lead Generation & Conversion Engine

Adapted from the AI Marketing Engine for finding and converting businesses that need a modern static website.

**Offer:** Turn-key agency-quality static website + full codebase handover.  
**CTA:** Stripe payment.  
**Proof:** 90-second old → new demo video.

---

## Target Profile

- **Tiers:** L1A, L1B, L1C, L2 multi-door, L2 platform
- **Geography:** Any USA zip code
- **Signals:**
  - Yelp / Google Maps / Facebook reviews ≥ 3.5–4★
  - No website, outdated website, or clearly weak presence
  - Solo operator, small team, newer business, or franchise with poor web (e.g. multi-door operations with “shitty website”)
- **Ideal:** Real local businesses that already get reviews but lose trust or traffic because of their site

## Daily Pipeline

### 1. Discovery (Daily Report)
Super Grok Heavy agents search and qualify:

- Businesses matching the review threshold
- Presence check (no site / outdated / weak)
- Tier classification (L1A–C / L2 multi-door / L2 platform)
- Basic contact surface (email, phone, Facebook, etc.)

**Output:** Daily qualified lead report (name, location, tier, review score, website status, contact points, notes).

### 2. Qualification Gate
Human (or strict rules) reviews the daily report and selects which leads move forward.

### 3. Site Build (Turn-key Static)
For each selected lead:

- Grok Build generates a clean, modern static site tailored to the business
- Agency-quality design + full codebase ready for handover
- Stored as a previewable package

### 4. Proposal Letter
Auto-generated, personalized proposal that includes:
- Observation of current web presence (or lack)
- What the new site delivers
- Codebase handover promise
- Clear price + Stripe payment link

### 5. 90-Second Demo Video
Old site (or “no site”) → New site walkthrough.  
Produced via Higgsfield or recorded Loom-style.  
Used as the primary visual proof in outreach.

### 6. Three-Stage Email Sequence

| Stage | Timing | Purpose |
|-------|--------|--------|
| Day 1 | Immediate | Personalized intro + demo video + soft value |
| Day 3–4 | Follow-up | Reinforce problem + show the finished site again + Stripe CTA |
| Day 7 | Final | Clear close / last look + easy payment link |

All emails generated by Grok Build from templates + lead-specific context.

### 7. Stripe CTA
Single clear payment path.  
On payment → deliver site files + codebase + any launch support notes.

### 8. Results → gBrain
What converted, what didn’t, reply rates, objections → written back into the local brain so future daily runs and proposals improve.

---

## Operating Rhythm

1. Morning: Super Grok Heavy runs discovery → daily report lands.
2. You (or rules) select the day’s leads.
3. Grok Build produces site + proposal + email sequence + demo brief.
4. Higgsfield (or Loom) produces the 90s video.
5. Outreach sequence is scheduled / sent.
6. Stripe handles payment; delivery is triggered.
7. Results logged back to gBrain.

---

## Key Design Rules

- Prefer agentic web reading (Grok Build connectors / browse tools) over brittle scrapers.
- Human gate on which leads receive a full site build (cost control).
- Every site is static, clean, and handed over with the codebase.
- Demo video is the main persuasion asset.
- Stripe is the only payment CTA.
- Everything compounds through the local gBrain.

# AI Marketing Engine
**GrokTerm + Super Grok Heavy + Higgsfield Edition**

One idea in → shipped campaign out.  
Harnesses · Loops · Graphs · Model Routing · Human Sign-off · Visual Render

---

## Stack

| Layer | Tool |
|-------|------|
| Primary host | **GrokTerm** (Windows exe / multi-tab terminal) |
| Reasoning & multi-agent | **Super Grok Heavy** |
| Agent loops & graphs | **Grok Build** |
| Deeper editing | Cursor Pro (Grok 4.5) — secondary |
| Media / video / static creative | **Higgsfield.ai Ultra** |
| Company brain (gBrain) | Local markdown + YAML (or Postgres) |

---

## Pipeline Stages

### 1. Raw Campaign Idea
You dictate or ramble (voice or text).  
GrokTerm + Grok Voice (or direct text) turns the mess into a clean brief.

**Runtime:** GrokTerm session

### 2. Ideation
Generate angles and directions. Kill most, keep the few that matter.  
Run under **Super Grok Heavy** (parallel agents explore and ruthlessly prune).

**Runtime:** SGH multi-agent mode inside GrokTerm

### 3. Research + Context
Always run both internal and external:

- **Internal (gBrain)** — past campaigns, brand voice, ICPs, SOPs, wins & losses (local MD/YAML or DB)
- **External** — market, competitors, current hooks

**Runtime:** Super Grok Heavy + local project files

### 4. Synthesis
Models merge research into a coherent plan.  

**Model Routing:**
- Super Grok Heavy → thinking, strategy, judgment
- Faster / lighter Grok calls → volume expansion
- Video/image models only when needed later

**Runtime:** SGH + Grok Build inside GrokTerm

### 5. Sign-off (Human Gate — Mandatory)
You evaluate the plan against your protocols and taste.  
This gate is non-negotiable.

**Runtime:** You + GrokTerm (or Cursor for side-by-side review)

### 6. Build the Campaign
Two native Grok Build modes:

- **LOOP** (one task) — draft → check → fix until it passes
- **GRAPH** (many parts) — explicit nodes + routes; agents travel the map you drew

**Runtime:** Grok Build agent loops + YAML/MD graph files in GrokTerm tabs

### Media / Visual Render (Higgsfield Node)
Once scripts, angles, and creative briefs clear sign-off:

| Asset type | Tool |
|------------|------|
| Static creative, hooks, angles | Higgsfield.ai Ultra |
| Video scripts → rendered video | Higgsfield.ai Ultra |
| UGC-style ads, demos, explainers | Higgsfield.ai Ultra |
| Landing page / blog visuals | Higgsfield + light polish |

Treat Higgsfield as a specialized **render node** in the graph, not the brain.

### Deliverables (Verticals)
- Landing pages (hero + offer copy, sales pages, CTAs, A/B variants)
- Blog / SEO (pillar articles, how-to guides, comparison pages)
- Guides / Magnets (ebooks, checklists, templates, whitepapers)
- Video (scripts, UGC ads, explainers, demos, VSLs)
- Social (threads, long posts, carousels, shorts, reels)
- Email (welcome flow, newsletters, nurture, launch)
- PR / Earned (press releases, media pitches, founder bylines)
- Paid Ads (hooks + angles, static creative, video variants)

### Results → Feedback
Conversion data, what worked, what died  
→ written back into local **gBrain**  
→ becomes better priors for the next campaign.

---

## Operating Rhythm

1. Open GrokTerm → create a campaign project folder.
2. Dictate the raw idea (Voice or text).
3. Spin Super Grok Heavy for ideation + research.
4. Synthesize → you sign off.
5. Kick Grok Build loops / graphs for structure and copy.
6. Send locked creative briefs to Higgsfield.ai Ultra for visuals/video.
7. Ship → log results back into the local brain.

---

## Key Design Rules

- Human sign-off remains a hard gate before expensive media generation.
- Super Grok Heavy owns judgment and parallel exploration.
- Grok Build owns the loops and explicit graphs.
- Higgsfield owns pixels and motion only.
- Everything feeds the local gBrain so the system compounds.
